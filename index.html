What this is

Small on purpose

Each game is a single self-contained page. Plain HTML, CSS, and JavaScript with zero dependencies, so they load instantly and will still work in a decade.

Original work

Every game, mechanic, and piece of art here is made from scratch. The format is a hub of tiny experiments — the content is not borrowed from anyone.

Respects your machine

No trackers, no analytics, no autoplaying audio. Progress is stored locally in your browser and animations back off when your system asks them to.
